# 2026-10-29

## Strand design system — v2.0 "sea-glass" rebuild

Full redesign of `/design-system/strand` (Case 07), executed against the
`sunnyside-brand-system` skill.

**Concept.** Sea-glass over dune light: one pane per view, a solid plate for any
paragraph, marine ink, one sun-warm signal at ~2% of the viewport, a coast that
appears twice (framed hero, full-bleed footer).

**Decisions**
- Mark replaced: the v1.2 S-monogram is gone. v2.0 is two sheared quadrilaterals
  (18.4° shear) with a six-unit channel — `M26 9H58L52 27H20Z` (sun) and
  `M12 33H52L46 55H6Z` (marine). Compact variant widens the channel to 7 units.
- Display face moved Syne → Instrument Sans (already available via `next/font`).
- Wordmark is Helvetica Neue Medium outlined at −22/1000, frozen as paths.
- Signal moved tide-green → sun `#A85A22`; night-sun `#E9A469`.
- Footer is a full-bleed `background-image` (not `<Image>`) so it escapes the
  max-width shell; scrim gradient is what keeps the lockup legible.
- Page structure follows the Clearing case: fixed topbar, contents rail, 11
  sections, full-bleed footer.

**Files**
- `features/strand/tokens.json` (v2.0.0, material `sea-glass`, 127 declarations,
  11 measured contrast pairs), regenerated by `scripts/generate-strand-tokens.mjs`.
- `features/strand/wordmark-path.ts` — normalized y-down outline, viewBox
  `0 0 2739 728`. **The raw fontTools path is y-up; never render it without the
  flip.** (v1 files carried a `scale(1,-1)` wrapper for this reason.)
- `features/strand/strand-data.ts` — all page copy and tables.
- `features/strand/strand.module.css` (~1560 lines) — pane, plate, marks, palette,
  type, parts, motion, voice, tokens, audit, footer.
- `app/design-system/strand/{page,layout}.tsx`, `llms.txt/route.ts`.
- `public/brand/strand/*` — marks, lockups, wordmarks, favicons, `mark-1024.png`,
  `strand-brandkit.png` (1500×1125), `dune-quiet-divider.webp`.
- `design/brand/strand/{story,brief,README}.md`, `brandkit.html`,
  `strand-brandkit.png` (3000×2250).
- `docs/strand-design-system-audit.md` rewritten for v2.0.

**Gates (re-derived, not asserted)**
- `score-mark.py` → PASS, dominant field 61%. Needs
  `/opt/homebrew/bin/python3` (has cairosvg) + `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib`.
- `detach-check.mjs` → 81 Cove · 75 Vitrine · 73 Hachure · 69 Riso · 59 Clearing.
  **Worst pair 59/100 vs floor 70 — FAIL, disclosed on the page and in the docs.**
  Sun (OKLCH 52°) sits 9° from Clearing's hart (61°). The old DETACH_SCORES in
  `strand-data.ts` were invented numbers (78/81/84/86/72); replaced with measured
  values and the two sub-floor rows now render in the `open` colour.

**Gotchas learned**
- Playwright is only installed as `@playwright/test` (pnpm); scripts must live in
  the repo root to resolve it. Use `channel: 'chrome'`.
- Element screenshots include fixed headers — don't read that as overlap.
- `.stageClear img` never matched the inline SVG; use `.stageClear svg`.
- `durBar` used to animate scaleX, which made three different durations look
  identical in every screenshot; now widths are proportional (38.1 / 61.9 / 100).
- Night glass over a bright photo turns pale: `.heroPane` carries its own night
  scrim so ink sits on a declared ground.

## Riso Co. v4.0 + Huginn v3.0 — rebuilt from their footers

Both design systems were replaced, in order, from the thing each one already
ended on: the pushpin-tear footer (Riso) and the Wild Hunt footer (Huginn).
The footers are kept and are now the *source* of each identity, not its last
panel.

**Riso Co. v4.0 — "one pin holds the sheet, the tear is what the second drum prints"**
- Mark: a sheet pinned at the top, torn from the pin; drum A's flap + drum B's
  flap slid 4,3; the pin is the only shape that crosses the tear. 64 grid,
  3 primitives, fill only, no circles.
- Variants: primary, compact (32 grid, 2 shapes, no pin), mono stamp (pin
  punched with `fill-rule: evenodd`), reverse (paper+carbon, for the orange
  sheet), glyph, wordmark (unchanged, Space Grotesk 700 outlined), three
  lockups, favicons 16/32/180.
- Page: `app/design-system/riso` is now a TSX specimen (was already TSX, but the
  module, data and components are new). Sections: pin, tear, marks, ink, type,
  parts, sheet, tokens, audit. `--rs-*`, safelight under `html[data-riso]`.
- Board re-rendered from `design/brand/riso/brandkit.html` (copy + tear panel
  replaced).

**Huginn v3.0 — "one 14-unit cell draws the painting, the name and the mark"**
- Mark: 5 cells in a 2×2+1 grid, the 6th six units off-grid and vermilion. The
  wordmark is the same cell in 22 rows (unchanged file).
- The iframe specimen is gone: `app/design-system/huginn` is a TSX page now, and
  `public/design-system/huginn/` (141KB static copy) is deleted, along with the
  `X-Frame-Options: SAMEORIGIN` exemption in `next.config.mjs` that existed only
  for that iframe.
- Sections: cell, dissolve, marks, field, type, parts, surface, tokens, audit.
  `--hg-*`, night under `html[data-huginn]`.
- New display face: Bodoni Moda (`--font-bodoni`, preload false). The dither is
  demonstrated twice — once on canvas (footer), once as a 22×22 markup plate
  computed from the same 4×4 Bayer matrix, so the rule is readable with JS off.

**Gotchas worth keeping**
- `currentColor` never crosses into an SVG loaded via `<img>` — it resolves to
  black. Every lockup bakes its ink (`scripts/build-lockup.mjs --ink`).
- `gap: 1px; background: var(--rule)` grids show a solid rule-coloured hole
  whenever the last row is partial. Use 2 columns for 4 items, 3 for 6, or make
  the list a ledger of rows.
- `.plate span { background: transparent }` outranks `.plateOn` (class+element
  beats a lone class), which silently erased every dither cell. Don't declare a
  default background on the child if a modifier sets it.
- Element screenshots include the sticky header; a "clipped" stage is usually
  just the topbar in the frame.
- `scripts/render-riso-board.mjs` needed `playwright-core`, which is not
  installed. Render boards with `@playwright/test`'s chromium from the repo root
  (`deviceScaleFactor: 2`, `document.fonts.ready` first).

**Second pass — heroes as posters, footers last**

- Both heroes are now full-bleed posters built from the footer's own parts.
  Riso: one orange sheet, pinned, torn along the bottom (22 teeth, irregular
  depths 2.0–4.4%), with the footer's chrome row (icons, live status, run
  number, Berlin clock) printed across the top. The mark uses the `onDrum`
  variant because the two-drum mark cannot sit on drum A.
- Huginn: painting → field → bone plate. The field carries only the display and
  the mark; all small type is on the plate, per the system's own "no type below
  24px on the field" rule. The dither is a canvas (6px cells derived from the
  element width) with a CSS fade as the no-JS fallback.
- Both footer bands moved to the end as section 09, outside the shell, so they
  are edge to edge by being blocks rather than by escaping a column. Sections
  renumbered: tokens 07, audit 08, the sheet/surface 09; NAV order follows.
- Fixed the voice block: it reused `.rejectList` (a `200px 1fr` grid), so the
  "Not: …" span landed in the label column. Now `.voiceList` with the bad
  example struck through under the sentence.
- Trap: replacing a whole CSS section silently drops classes the markup still
  uses. `.btn`, `.ditherOverlay`, `.stat`, `.display`, `.eyebrow` all vanished
  once; a `styles.X` → defined-class diff caught it in one command.
