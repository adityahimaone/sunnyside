# 2026-10-29

## Strand design system — v2.0 "sea-glass" rebuild

Full redesign of `/design-system/strand` (Case 07), executed against the
`sunnyside-brand-system` skill.

**Concept.** Sea-glass over dune light: one pane per view, a solid plate for any
paragraph, marine ink, one sun-warm signal at ~2% of the viewport, a coast that
appears twice (framed hero, full-bleed footer).

**Decisions**
- Mark replaced: the v1.2 S-monogram is gone. v2.0 is two sheared quadrilaterals
  (18.4° shear) with a six-unit channel — `M26 9H58L52 27H20Z` (sun) and
  `M12 33H52L46 55H6Z` (marine). Compact variant widens the channel to 7 units.
- Display face moved Syne → Instrument Sans (already available via `next/font`).
- Wordmark is Helvetica Neue Medium outlined at −22/1000, frozen as paths.
- Signal moved tide-green → sun `#A85A22`; night-sun `#E9A469`.
- Footer is a full-bleed `background-image` (not `<Image>`) so it escapes the
  max-width shell; scrim gradient is what keeps the lockup legible.
- Page structure follows the Clearing case: fixed topbar, contents rail, 11
  sections, full-bleed footer.

**Files**
- `features/strand/tokens.json` (v2.0.0, material `sea-glass`, 127 declarations,
  11 measured contrast pairs), regenerated by `scripts/generate-strand-tokens.mjs`.
- `features/strand/wordmark-path.ts` — normalized y-down outline, viewBox
  `0 0 2739 728`. **The raw fontTools path is y-up; never render it without the
  flip.** (v1 files carried a `scale(1,-1)` wrapper for this reason.)
- `features/strand/strand-data.ts` — all page copy and tables.
- `features/strand/strand.module.css` (~1560 lines) — pane, plate, marks, palette,
  type, parts, motion, voice, tokens, audit, footer.
- `app/design-system/strand/{page,layout}.tsx`, `llms.txt/route.ts`.
- `public/brand/strand/*` — marks, lockups, wordmarks, favicons, `mark-1024.png`,
  `strand-brandkit.png` (1500×1125), `dune-quiet-divider.webp`.
- `design/brand/strand/{story,brief,README}.md`, `brandkit.html`,
  `strand-brandkit.png` (3000×2250).
- `docs/strand-design-system-audit.md` rewritten for v2.0.

**Gates (re-derived, not asserted)**
- `score-mark.py` → PASS, dominant field 61%. Needs
  `/opt/homebrew/bin/python3` (has cairosvg) + `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib`.
- `detach-check.mjs` → 81 Cove · 75 Vitrine · 73 Hachure · 69 Riso · 59 Clearing.
  **Worst pair 59/100 vs floor 70 — FAIL, disclosed on the page and in the docs.**
  Sun (OKLCH 52°) sits 9° from Clearing's hart (61°). The old DETACH_SCORES in
  `strand-data.ts` were invented numbers (78/81/84/86/72); replaced with measured
  values and the two sub-floor rows now render in the `open` colour.

**Gotchas learned**
- Playwright is only installed as `@playwright/test` (pnpm); scripts must live in
  the repo root to resolve it. Use `channel: 'chrome'`.
- Element screenshots include fixed headers — don't read that as overlap.
- `.stageClear img` never matched the inline SVG; use `.stageClear svg`.
- `durBar` used to animate scaleX, which made three different durations look
  identical in every screenshot; now widths are proportional (38.1 / 61.9 / 100).
- Night glass over a bright photo turns pale: `.heroPane` carries its own night
  scrim so ink sits on a declared ground.
