What each one contains

A specimen page with the idea, the mark, the colour, the type, the form kit, the applications, the tokens and the audit. Nothing is a screenshot.

What is generated

Marks, boards, token sheets and exports are built by a script from a single source. Editing the output by hand does not survive the next build, and the audit says so.

What is measured

Contrast is recomputed from hex, not typed. Every palette prints the pair that fails and the job it may therefore not do. A palette that only publishes its passes is a brochure.
